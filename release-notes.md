# Daltoon X 1.0.0

First release of Daltoon X for Windows. This build is not signed with Authenticode, so Windows may show an unknown-publisher warning on first run; updates from this version onward are verified cryptographically.

- Gaming, performance and power tuning
- Privacy, telemetry and advertising cleanup
- Scheduled-task and startup-item control
- Restore points and a rollback journal for applied changes
- Browser, cookie and disk-maintenance tools
- Arabic, English, French, German, Italian, Portuguese and Spanish
- Online applications catalog with signed, checksum-verified installers
- Automatic updates with signature verification
